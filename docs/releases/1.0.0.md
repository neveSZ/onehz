# OneHZ 1.0.0

First public stable release.

## Highlights

- Refresh-rate staircase with 1–5 tiers.
- Normal, ECO (battery saver), and AOD profiles.
- AOD brightness with a safety band and restore action.
- Per-app profiles and video mode.
- Guided setup through Shizuku, no root, no accessibility service.
- Diagnostics, themes, and PT-BR / EN / ES languages.

## Tested on

Samsung Galaxy S25+ (`SM-S936B`), Android 17 (API 37), One UI 9.0, build
`S936BXXUDDZJB`. Only this device was tested.

## Requirements

- Samsung LTPO phone;
- Android 12+;
- Shizuku running (tested with the thedjchi fork `v13.7.0-thedjchi`).

## Notes

- Uninstall any debug build signed with a different key before installing this APK.
- Disable AOD brightness before uninstalling; if the key remains, delete
  `debug_aod_brightness`.
- All features are free. Donations are optional and never unlock features.
- English and Spanish translations are AI-generated and not reviewed by native
  speakers.
- OneHZ includes portions derived from Adaptive Hz (MIT, © 2025 Mahmut Alperen Ünal).
  See `NOTICE`.
