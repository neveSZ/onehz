# OneHZ 1.2.2-beta.1

Beta for the next 1.2.2 patch. It fixes per-app profiles not applying right after an app
switch, makes Diagnostics visible in Settings, and changes the Sleep charging guard to a
positive switch that keeps Doze active while charging by default.

## Highlights

- **Per-app profiles follow app changes.** OneHZ now listens for foreground changes through
  the Shizuku UserService, so opening an app from the launcher, recents, or a notification
  applies its profile before the first touch. If the platform rejects the hidden listener,
  the engine falls back to one uncached foreground read after touch-up.
- **Diagnostics is always available.** Settings now shows the engine report without the
  seven-tap unlock, and the one-way hide toggle is gone.
- **Doze while charging.** Sleep now keeps Doze active while the device is plugged in by
  default. The old "Pause while charging" switch is replaced by a positive
  **Doze while charging** switch. Explicit 1.2.1 choices are preserved, and old backups are
  still imported correctly.
- **Better diagnostics.** The report includes the foreground app, its source (task-stack
  listener or touch probe), the active profile, the active layer and the app layer.

## Upgrade

Install over 1.2.1. The signing key and package are unchanged, and `versionCode` 1020201
lets beta users move to the future stable release.

## Known limitations

- The task-stack listener uses hidden platform APIs. On devices where it is unavailable,
  OneHZ falls back to the touch-up foreground read.
- Xiaomi/HyperOS behavior is unchanged; the fast per-app path was validated on Samsung.

## Verification

- Unit tests, lint, debug and release builds pass.
- Signed release installed over 1.2.1 on a Galaxy S25+ (Android 17 / One UI 9).
- Per-app profile applied after `am start` without a touch; switching back returned the
  global profile.
- Diagnostics visible without the seven-tap unlock.
- Sleep charging switch defaults on; disabling it pauses Doze while charging.
