# OneHZ 1.2.0

First stable release after 1.1.0-beta.1. This release adds reusable profiles, backup and
Sleep, and reviews the Home hierarchy, naming and content. It is a recommended update for
everyone on 1.0.1 and for beta users.

## Highlights

- **Reusable profiles.** Economy, Balanced and Performance are generated from the device
  panel. Create, rename, edit, reset and delete profiles, then assign apps to a profile
  instead of copying a refresh-rate staircase.
- **Automatic Economy.** Optional toggle in **Manage profiles** that switches to the
  Economy profile while the system battery saver is on.
- **Sleep (forced Doze).** Optional deep/light idle with a time window, charging and music
  guards, pause, a wake-up app list, and local 24-hour measurements. A confirmation with
  the notification/VoIP warning appears before the first enable.
- **AOD detail screen.** Always uses the lowest rate exposed by the panel and explains it.
  On Samsung, brightness can be controlled and restored to the system value.
- **Home reorganized.** Status, selected profile and “screen off” are the main hierarchy;
  AOD and Sleep open dedicated detail screens. Home shows the real control state, the
  profile in use, and the last app assignment.
- **Backup and restore.** Dedicated screen with explicit “Includes” / “Does not include”
  lists. The JSON includes profiles, assignments, video rules and Sleep settings; the
  system Doze whitelist is not included. Backups created before Sleep existed do not
  change the Sleep configuration on import.
- **Clearer names and copy.** Portuguese profile names are **Economia / Equilibrado /
  Desempenho**; “ECO” and “Normal” are no longer used in the UI. Portuguese, English and
  Spanish strings were revised, including plurals and error messages.

## Other changes

- Per-profile video settings with a global forced-app list and a shortcut in the profile
  card.
- Per-app assignments explain that they reference a profile and that editing it affects
  every app using it.
- Setup explains that the Doze exception is for OneHZ only and is not the Sleep feature.
- Import adapts unsupported refresh rates to the current panel and reports the result.
- Migration from the legacy Normal/ECO profiles and copied per-app staircases.
- Fastlane descriptions and screenshots updated; Spanish store listing added.

## Upgrade

Install this APK over 1.0.1 or 1.1.0-beta.1. It uses the same signing key, and your settings
are kept. The `versionCode` is higher than both, so beta users return to the stable
channel. If Shizuku is running, OneHZ reconnects automatically.

## Known limitations

- Tested on a Samsung Galaxy S25+ (`SM-S936B`, Android 17 / One UI 9) and a POCO X7 Pro
  (`2412DPC0AG`, Android 16 / HyperOS 3). Other models are untested.
- On the tested POCO X7 Pro, 30 Hz is dimmer at the panel level. OneHZ cannot compensate;
  the app warns in the profile editor.
- PiP video is not detected yet.
- Shizuku must be running; it may need to be restarted after a reboot.
- Do not run another refresh-rate controller at the same time.
