# OneHZ 1.2.1-beta.2

Second beta of the 1.2.1 patch. Keeps the AOD/Sleep hierarchy fixes from 1.2.1-beta.1 and
modernizes the app internals: storage, UI state, icons, edge-to-edge, Baseline Profile,
and release tooling. There are no new user-facing features.

> **Pre-release.** This build is published for testing and is not offered to the stable
> channel. Install it manually, enable the pre-release channel in the app, or enable
> pre-releases in Obtainium.

## Highlights

- **DataStore storage.** Preferences moved to DataStore behind a synchronous facade. On
  the first start the legacy `onehz_prefs.xml` is migrated automatically and cleared, so
  profiles, app assignments, AOD, Sleep and video settings are kept.
- **Baseline Profile.** Startup and common paths are compiled ahead of time; the profile
  is installed by `androidx.profileinstaller`.
- **Smaller icon dependency.** The 57 used Material Symbols are bundled as vector
  drawables; `compose-material-icons-extended` is gone.
- **Edge-to-edge and predictive back.** Content draws behind the system bars, with
  theme-driven icon appearance.
- **UI state.** Screens collect state through small ViewModels and stop collecting when
  they leave the foreground.
- **Tooling.** Version validation/bump scripts, Android SDK caching, secret scanning and
  dependency review in CI.

Kept from 1.2.1-beta.1: the single AOD master on Home, independent rate/brightness, Sleep
options visible while off, and the AOD backup field.

## Upgrade

Install over 1.2.0 or 1.2.1-beta.1. It uses the same signing key and your settings are
kept; the DataStore migration runs once on first start.

> **Downgrade warning.** After the migration the legacy XML is empty. Reinstalling
> 1.2.0/1.2.1-beta.1 later shows defaults for preferences changed after the migration.
> Export a backup first if you may need to roll back.

The final 1.2.1 stable will use a higher `versionCode` (1020200), so beta users can move
to the stable channel by installing it over this beta.

## Verification

Tested on a POCO X7 Pro (`2412DPC0AG`, Android 16 / HyperOS 3): migration from the 1.2.0
preferences, Home/Apps/Settings/Backup/Profiles/AOD/Sleep/Diagnostics navigation, search
fields, sliders, sheets, engine control (Shizuku) and the Baseline Profile generator. The
Samsung path was code-reviewed but not device-tested for this beta.
