# OneHZ 1.2.2-beta.2

Second beta for the 1.2.2 patch. It keeps the per-app foreground fix from beta 1 and makes
the battery-saver exception for app profiles visible when the app is added, not only when
it is edited.

## Highlights

- **The exception is visible when it matters.** Adding an app now shows the same
  **Keep this app's profile during battery saver** switch as the edit sheet. Before this
  change, the option only appeared after the app was assigned, so an app added from that
  sheet silently followed automatic Economy while battery saver was on.
- **Clearer badge.** An app that keeps its profile shows **Keeps its profile** instead of
  **Economy ignored**, with the normal accent color instead of the warning color.
- **Hint when Automatic Economy is on.** Both sheets explain that automatic Economy
  replaces the app profile unless the switch is on. The hint is hidden when Automatic
  Economy is off.
- **Disabled where it has no effect.** The switch is disabled for the Economy profile,
  because there is no separate app profile to keep.

No policy change: with battery saver on and Automatic Economy enabled, Economy still wins
unless the app keeps its own profile.

## Upgrade

Install over 1.2.2-beta.1. The signing key and package are unchanged, and `versionCode`
1020202 lets beta users move to the future stable release. App assignments and profiles are
kept.

## Known limitations

- The task-stack listener uses hidden platform APIs. On devices where it is unavailable,
  OneHZ falls back to the touch-up foreground read.
- Xiaomi/HyperOS behavior is unchanged; the fast per-app path was validated on Samsung.

## Verification

- Unit tests, lint, debug and release builds pass.
- Signed release installed over 1.2.2-beta.1 on a Galaxy S25+ (Android 17 / One UI 9).
- Adding an app with the switch on applies its profile while battery saver is on; the row
  shows **Keeps its profile**.
- Disabling the switch returns the app to Economy while battery saver is on.
- With battery saver off, the assigned profile applies as before.
- The switch is disabled for the Economy profile in both sheets.
