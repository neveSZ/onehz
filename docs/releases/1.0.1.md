# OneHZ 1.0.1

Second stable release. This is the first version with the optional in-app update
checker.

## Highlights

- Optional GitHub update check, **off by default**. Enable it in
  **Settings → Updates** and accept the consent dialog.
- Checks happen only when you open OneHZ, at most once per chosen interval
  (24 hours, 3 days, 7 days, or 30 days). Nothing runs in the background.
- **Stable only** or **stable + pre-releases** channel. Pre-releases are clearly
  labeled and can be disabled at any time.
- Dismissible Home banner with a direct link to the release, plus a manual
  **Check now** action and a GitHub Releases link in Settings and About.
- Privacy: `INTERNET` is used only for the opt-in check. No token, account,
  identifier, telemetry, or automatic APK installation.
- Support links in **About → Support OneHZ**:
  - GitHub Sponsors for international supporters;
  - LivePix for supporters in Brazil (Pix/BRL).
- Standardized **About → Credits** section.

## Upgrade

Install this APK over 1.0.0. It uses the same signing key, and your settings are kept.
If Shizuku is running, OneHZ reconnects automatically.

Version 1.0.0 does not include the update checker, so this update is manual. From 1.0.1
onward, the app can notify you about future releases when you enable the option.
