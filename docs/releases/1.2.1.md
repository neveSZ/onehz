# OneHZ 1.2.1

First stable release of the 1.2.1 patch. It includes the AOD/Sleep hierarchy fixes from
1.2.1-beta.1 and a broad internal modernization: DataStore, ViewModels, bundled icons,
edge-to-edge, Baseline Profile, and release tooling.

Available from **Shizu Store**, GitHub Releases and Obtainium. OneHZ is not on Google
Play.

## Highlights

- **AOD parity.** The rate switch now appears on every supported device. The Home switch
  remains the only AOD master; rate and brightness are independent. On devices without
  the Samsung AOD brightness key, the brightness row stays visible as a disabled switch
  that explains the panel manages it automatically.
- **Sleep detail redesign.** The Home switch is the only master. The detail uses the same
  "How it works" card as the profile editor, shows the behavior options and measurements
  even when Sleep is off, keeps one dismissible warning, and only shows a status line for
  active, paused or failure states.
- **Clearer video settings.** The minimum rate is separated from the detection rules.
  Detection opens a focused sheet with the four rules and the global forced-app list; the
  card shows the active rule count and warns when no positive signal is enabled.
- **DataStore.** Preferences moved to DataStore behind the synchronous facade, with a
  one-time migration from the legacy `onehz_prefs.xml`. Profiles, app assignments, AOD,
  Sleep and video settings are kept.
- **Faster startup.** A Baseline Profile is generated on-device and installed by
  `androidx.profileinstaller`. The 57 used Material Symbols are bundled as vector
  drawables, removing `compose-material-icons-extended`.
- **Modern UI base.** Edge-to-edge layout, predictive back, ViewModel state holders,
  `TextFieldState`, slider state APIs, explicit bottom-sheet states, and typed package
  queries.

## Upgrade

Install over 1.2.0 or 1.2.1-beta.1. The signing key is unchanged and your settings are
kept; the DataStore migration runs once on first start.

> **Downgrade warning.** After the migration the legacy XML is empty. Reinstalling
> 1.2.0 or 1.2.1-beta.1 later shows defaults for preferences changed after the migration.
> Export a backup first if you may need to roll back.

`versionCode` 1020200 is higher than 1.2.1-beta.1 (1020101), so beta users move to stable
by installing this APK over the beta.

## Verification

- Tested on a POCO X7 Pro (`2412DPC0AG`, Android 16 / HyperOS 3): migration from 1.2.0
  preferences, Home, Apps, Settings, Backup, Profiles, AOD, Sleep and Diagnostics,
  search fields, sliders, sheets, Shizuku control and the Baseline Profile generator.
- Tested on a Samsung Galaxy S25+ (`SM-S936B`, Android 17 / One UI 9): AOD rate and
  brightness, Sleep, profiles and backup.
- Unit tests and `lintDebug` are clean; the release build uses R8, resource shrinking and
  the generated Baseline Profile.

## Known limitations

- AOD brightness is Samsung-only because the key (`debug_aod_brightness`) is not exposed
  on Xiaomi/HyperOS. The option is shown disabled there instead of being hidden.
- Removing the app while AOD brightness is active can leave the Samsung key behind;
  disable AOD brightness first or run
  `adb shell settings delete system debug_aod_brightness`.
- 30 Hz is dimmer at the panel level on the tested POCO X7 Pro; OneHZ warns in the
  profile editor instead of faking a compensation.
- PiP video is not detected yet.
- Shizuku must be running; it may need to be restarted after a reboot.
- Do not run another refresh-rate controller at the same time.
