# OneHZ 1.1.0-beta.1

First beta after 1.0.1. This release adds Xiaomi/Redmi/POCO support, replaces the LTPO
requirement with a capability check, and makes video detection configurable.

> **Pre-release.** This build is published for testing and is not offered to users on the
> stable channel. Install it manually, enable the pre-release channel in the app, or
> enable pre-releases in Obtainium.

## Highlights

- **Xiaomi/Redmi/POCO support** through `secure/miui_refresh_rate` (HyperOS 2/3) and
  `secure/user_refresh_rate` (HyperOS 1 fallback). The HyperOS rate key is snapshotted
  and restored when control is released.
- **No LTPO requirement.** The gate now accepts any Samsung or Xiaomi/Redmi/POCO display
  that exposes at least two refresh rates (for example 120/90/60/30).
- **New default profiles** on a fresh install:
  - normal: **panel maximum → 60 Hz → panel minimum**, holding 2 s and 5 s;
  - ECO: **60 Hz → panel minimum**, holding 2 s.
- **Configurable video detection**: toggle MediaSession, the paused-session veto, the
  video-decoder requirement, and the media-audio requirement. Add apps that must always
  be treated as video, even without a session, decoder, or audio.
- **Diagnostics** now report screen brightness/mode, battery-saver state, and the active
  rate route.
- **30 Hz warning** in the profile editor on Xiaomi, where the panel is dimmer at 30 Hz.
- AOD brightness remains Samsung-only and is hidden on Xiaomi.

## Upgrade

Install this APK over 1.0.1. It uses the same signing key, and your settings **and
existing profiles are kept**. The new default profiles apply only to fresh installs.

The next stable release uses a higher `versionCode`, so installing it over this beta
returns you to the stable channel.

## Known limitations

- Tested on a Samsung Galaxy S25+ (`SM-S936B`, Android 17 / One UI 9.0) and a POCO X7
  Pro (`2412DPC0AG`, Android 16 / HyperOS 3.0). Other models are untested.
- On the tested POCO X7 Pro, 30 Hz is dimmer at the panel level. OneHZ cannot compensate;
  the app warns in the profile editor.
- PiP video is not detected yet.
- Shizuku must be running; it may need to be restarted after a reboot.
- Do not run another refresh-rate controller at the same time.
