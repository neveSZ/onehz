# OneHZ 1.2.1-beta.1

First beta of the 1.2.1 patch. Fixes the AOD switch hierarchy and keeps the Sleep options
available while the feature is off.

> **Pre-release.** This build is published for testing and is not offered to the stable
> channel. Install it manually, enable the pre-release channel in the app, or enable
> pre-releases in Obtainium.

## Highlights

- **One AOD master.** The AOD switch on Home is now the only master for the section. The
  detail screen no longer duplicates it. Turning the master off pauses rate and brightness
  without resetting their choices.
- **Rate and brightness are independent again.** Turning the rate off no longer hides
  brightness or its “Restore system brightness” action. On Samsung, brightness stays
  visible and editable even when the rate is off.
- **AOD master migration.** The new switch is derived from the existing rate/brightness
  choices on upgrade. Backups created by 1.2.0 remain compatible; new backups include
  `aodMasterEnabled`.
- **Sleep detail without a duplicate master.** The Sleep switch on Home is the only master.
  With Sleep off, the detail keeps the behavior options, wake-up apps and historical
  measurements visible and editable. “Test now” and pause/resume require Sleep to be on.
- **Clearer Sleep off state.** The Home subtitle now says “Off” when Sleep is disabled
  instead of describing what Doze does.

## Upgrade

Install this APK over 1.2.0. It uses the same signing key, and your settings are kept. The
AOD master is migrated automatically, and existing backups are still accepted.

The final 1.2.1 stable will use a higher `versionCode`, so beta users can move back to the
stable channel by installing it over this beta.

## Known limitations

- This beta was tested on a Samsung Galaxy S25+ (`SM-S936B`, Android 17 / One UI 9). The
  Xiaomi/POCO path was code-reviewed but not device-tested for this beta.
- On the tested POCO X7 Pro, 30 Hz is dimmer at the panel level. OneHZ cannot compensate;
  the app warns in the profile editor.
- PiP video is not detected yet.
- Shizuku must be running; it may need to be restarted after a reboot.
- Do not run another refresh-rate controller at the same time.
