## Screenshots

The README reuses the store screenshots from
`fastlane/metadata/android/<locale>/images/phoneScreenshots/`, so a release only needs one
set per language. Update them from the final build before tagging a release (see
[docs/RELEASING.md](../RELEASING.md)).

The OneHZ icon and branding assets are original work and are covered by the repository's
MIT license.
