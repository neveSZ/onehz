OneHZ keeps the refresh rate of Samsung and Xiaomi/Redmi/POCO displays under control: smoother when you touch the screen, quieter when you rest, and lighter when the screen is off.

It changes the display refresh rate through Shizuku only. There is no root requirement, no direct ADB from the app, no WRITE_SECURE_SETTINGS, and no AccessibilityService.

Features
* Reusable Economy, Balanced and Performance profiles, plus custom profiles.
* Manual profile selection with optional Automatic Economy while the system battery saver is on.
* Per-app assignments that reference a saved profile instead of copying its staircase.
* Per-profile video minimum and detection rules, plus a global forced-video app list.
* AOD always uses the panel minimum; Samsung-only AOD brightness with a safety band and a system restore action.
* Optional Sleep (forced Doze) with a first-enable warning, guards and local measurements.
* Backup and restore of profiles, app assignments, video, AOD, Sleep settings and the master switch.
* Device-aware default profiles on a fresh install.
* Guided setup for display compatibility, Shizuku, battery optimization, Doze, and notifications.
* Diagnostics, light/dark/AMOLED themes, and English, Portuguese (Brazil), and Spanish UI.

Requirements
* A Samsung phone or a Xiaomi/Redmi/POCO phone whose display exposes at least two refresh rates. LTPO is not required.
* Android 12 (API 31) or newer.
* Shizuku installed and running.

The Shizuku app is separate and is not bundled with OneHZ. OneHZ includes only the MIT-licensed Shizuku API client library. Without the Shizuku app, OneHZ cannot control the display. OneHZ is tested on the Samsung Galaxy S25+ (SM-S936B) with Android 17 / One UI 9.0 and on the POCO X7 Pro (2412DPC0AG) with Android 16 / HyperOS 3.0; other models and Android versions may work but are not tested.

Notes
* AOD brightness is Samsung-only and is hidden on Xiaomi.
* On the tested POCO X7 Pro, 30 Hz is dimmer at the panel level. OneHZ cannot compensate and shows a warning in the profile editor.
* Video in picture-in-picture is not detected yet.

Privacy
* No ads, analytics, telemetry, or accounts.
* Profiles and settings stay on the device.
* An optional update check is off by default. When enabled, it only reads the public GitHub Releases API when the app opens. It never downloads or installs an APK and never runs in the background.

Permissions
* QUERY_ALL_PACKAGES: list installed apps so you can create per-app profiles.
* RECEIVE_BOOT_COMPLETED: reapply the profile after a reboot.
* FOREGROUND_SERVICE / FOREGROUND_SERVICE_SPECIAL_USE: keep the optional engine service alive.
* POST_NOTIFICATIONS: show the foreground-service notification.
* REQUEST_IGNORE_BATTERY_OPTIMIZATIONS: optional, so the system does not kill the engine.
* INTERNET: only for the optional GitHub update check.
* Shizuku permission: perform the privileged display and settings operations.
